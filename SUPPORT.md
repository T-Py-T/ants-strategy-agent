# Support

For a focused support request, include the relevant command or reproduction,
the revision involved, and the evidence that was retained. Do not include
credentials, private keys, tokens, or other sensitive material.

## Where to ask

- Bugs and questions: open a [GitHub issue](https://github.com/T-Py-T/ants-strategy-agent/issues).
- Security problems: follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
- Setup and validation: see [CONTRIBUTING.md](CONTRIBUTING.md).
